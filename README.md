# ZayedReviews

Personal review website built with React, TypeScript, and Vite. 
Features an "Indie Web" aesthetic and a simple data-driven structure.

## Deployment
This project is configured for GitHub Pages via GitHub Actions.

## How to add reviews
Edit `src/data/reviews.ts` and add your thoughts to the `reviews` array.
The categories supported are: `Show`, `Game`, and `Opinion`.

## Tech Stack
- React 19
- TypeScript
- Vite
- Vanilla CSS
